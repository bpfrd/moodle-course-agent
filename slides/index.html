Slide 3 · Roles

What each piece does

Guardrail

Classifies each teacher message. Off-topic, sexual, hate, or violence is refused. Course content itself is not filtered by keywords.

Human in the loop

Reads and local file edits run freely. Every Moodle write pauses for yes or no in the shell.

Hooks

Lifecycle callbacks around a turn and each tool call. Used to log start, tool name, and end of an invocation.

Session manager

Stores the conversation on disk by session id, so a later shell can continue the same thread.

Conversation manager

Keeps a sliding window of recent messages so the context stays bounded as the chat grows.

Skills

Short playbooks (inspect, author, revise, templates, workspace, sync) the agent can load when the task matches.

MCP

One server with the same Moodle API, workspace, and sync tools. Other clients can call them over stdio; writes still need approval.
